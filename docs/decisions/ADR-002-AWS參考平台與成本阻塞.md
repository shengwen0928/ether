## 原問題（已取代，僅供追溯）

ETHER 的參考部署平台為何？正式部署的成本如何確認？

## 原選項（已取代，僅供追溯）

| 選項 | 說明 |
|---|---|
| A. AWS 為參考部署平台 | SPEC-SOURCE.md 原文：「雲：AWS 為參考部署平台。基礎設施：Docker＋Terraform；CI／CD：GitHub Actions。」 |
| B. 其他雲平台為參考 | 未經使用者指定，不得擅自更換（原技術棧「已確定，不得擅自更換」） |

## 原決定（已取代，僅供追溯）

選 A：AWS 為參考部署平台；開發期以本機 Docker Compose 為準；正式部署成本待查證且為阻塞項（使用者免費原則，不得新增付款方式）。

## 原理由（已取代，僅供追溯）

1. 參考平台只是「參考」，不代表已承諾付費部署；成本未查證前不得部署 production。
2. 開發期以本機 Docker Compose 為準，與 production 部署流程分離，避免在本機假裝 production 已驗證。

## 現行狀態

- 本 ADR 狀態為「已取代」，現行決策見 ADR-009、ADR-013。
- 成本阻塞仍然有效：正式部署成本待查證，仍可能付費項目（網域、伺服器、簡訊 OTP、Apple Developer、Google Play 上架、外部 AI API、TURN 頻寬等）須明列，不得宣稱全系統零成本；不得代使用者決定花錢或綁卡。
