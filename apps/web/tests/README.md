# ETHER Web — 測試（Phase 02）

本目錄的測試不新增任何依賴：

- `tests/run.mjs`：以 esbuild（Vite 的既有傳遞依賴）把 `entry-*.ts(x)` 打包成
  CommonJS，放進暫存目錄，再以 `node --test` 執行 `.mjs` 測試檔；結束後刪除暫存檔。
  執行方式（於 `apps/web`）：`node tests/run.mjs`
- `tests/logic.test.mjs`：`src/data/logic.ts` 純函式的單元測試。
- `tests/components.test.mjs`：以 `react-dom/server` 渲染元件的字串快照式測試
  （結構、無障礙屬性、狀態 class），不含瀏覽器互動測試；含 API 模式
  ChatsView 的載入狀態與資料來源標示（清單遷移里程碑），以及群組檢視
  雙模式的標題、載入狀態與資料來源標示（群組接線里程碑），以及媒體檢視
  雙模式的標題、載入狀態與資料來源標示（媒體接線里程碑；上傳表單與
  限制說明僅於載入完成後渲染，SSR 測試不及於此），以及已讀回條目標
  挑選純函式的單元測試（回條接線里程碑；effect 本身須瀏覽器實測），
  以及送達回條目標挑選與回條狀態推導純函式的單元測試（delivered
  回條接線里程碑；effect 本身須瀏覽器實測），以及建立對話對話框的 SSR 斷言與人選過濾純函式單元測試（建立對話
  里程碑；對話框的開啟、挑選與建立流程須瀏覽器實測），以及反應列
  與置頂區塊的 SSR 斷言（反應／置頂接線里程碑；挑選、寫入與清單
  載入的互動須瀏覽器實測），以及附件區塊、轉傳對話框與附件挑選
  對話框的 SSR 斷言與轉傳人選過濾／附件大小格式純函式單元測試
  （附件／轉傳接線里程碑；對話框的開啟、挑選、寫入與失敗重試須
  瀏覽器實測），以及附件區塊下載按鈕／不支援註記的 SSR 斷言
  （位元組上傳通道接線里程碑；下載互動須瀏覽器實測），以及自己訊息操作列的 SSR 斷言與編輯內容檢查純
  函式單元測試（編輯／收回／刪除接線里程碑；編輯框、確認對話
  框與寫入流程須瀏覽器實測），以及訊息搜尋面板的 SSR 斷言（搜尋
  接線里程碑；閒置表單、篩選控制、資料來源標示與不支援狀態，
  搜尋送出、載入更多與跳轉互動須瀏覽器實測），以及對話成員區塊、
  新增成員對話框與離開對話確認對話框的 SSR 斷言（成員管理接線
  里程碑；新增挑選、確認與寫入流程須瀏覽器實測），以及時間線檢視
  雙模式、貼文卡片與媒體挑選對話框的 SSR 斷言與貼文／留言內容
  檢查純函式單元測試（社群動態接線里程碑；發佈、按讚、留言、
  編輯、刪除與載入更多的互動須瀏覽器實測），以及通話檢視雙模式、
  通話卡片、響鈴中／已結束詳情與發起通話對話框的 SSR 斷言與狀態／
  時長／操作狀態純函式單元測試（通話接線里程碑；發起挑選、接聽／
  拒接／忙線／結束與載入更多的互動須瀏覽器實測），以及貼圖檢視
  雙模式、貼圖包卡片／詳情、貼圖方塊、建立／編輯對話框與新增
  貼圖對話框的 SSR 斷言與分類／狀態標籤／名稱檢查純函式單元
  測試（貼圖接線里程碑；分類篩選、搜尋送出、收藏切換、建立／
  編輯／刪除／新增／移除與載入更多的互動須瀏覽器實測）。
- `tests/api.test.mjs`（M2a／M2c／M3／M2d／M5 清單遷移／M6 群組接線／媒體接線）：以 stub `fetch` 測試 API 客戶端（錯誤封包、

  以及對話／訊息對映（游標參數、wire 順序、空游標、可空最後訊息欄位、歷史 401

  邀請／公告／設定端點呼叫與請求 shape、群組清單 401 清除 Token、展示資料群組操作
  與單一現行公告規則），以及媒體對映（上傳會話建立請求 shape／檔案與會話清單／取消／
  刪除／縮圖／授權檢查端點呼叫、檔案清單 401 清除 Token、展示資料媒體操作與掃描閘門），
  以及已讀回條（回條請求 shape 不含 device_id、回條 401 清除 Token），
  以及 delivered 回條與回條列表（delivered 請求 shape、列表對映、
  列表 401 清除 Token、展示資料回條記帳與去重），以及建立對話（建立請求 shape、既有對話 200 回應對映、建立 401 清除 Token、
  展示資料既有對話去重），以及反應與置頂（反應／置頂端點呼叫與請求 shape、
  彙總與置頂清單對映、反應 401 清除 Token、展示資料單一生效反應與置頂上限），
  以及附件與轉傳（附件列出／新增端點呼叫與請求 shape、轉傳端點呼叫與
  client_message_id、轉傳紀錄對映、附件 401 清除 Token、發送訊息附帶
  attachment_file_ids、展示資料附件掃描守衛與去重、展示資料轉傳內容
  複製不帶附件與深度上限），以及編輯／收回／刪除（編輯請求 shape 僅含
  content、編輯 401 清除 Token、展示資料編輯拒絕收回／已刪除訊息、
  展示快照收回／刪除佔位顯示），以及訊息搜尋（搜尋端點 snake_case
  參數組裝與 wire 回應對映、索引不可用 503、搜尋 401 清除 Token、

- `tests/contrast-check.mjs`：直接讀取 `tokens.css`，驗算關鍵文字／互動配對的
  WCAG 對比度（AA 4.5:1），含搜尋面板在對話清單欄表面上的時間文字與
  跳轉醒目外框配對，以及時間線貼文卡片沿用的文字／強調色配對，以及
  通話卡片沿用的文字配對，以及貼圖包卡片／貼圖方塊沿用的文字配對。執行：`node tests/contrast-check.mjs`
- `tests/responsive-audit.mjs`：靜態檢查響應式契約（斷點、單欄切換、reduced-motion），
  含搜尋面板欄內捲動、無固定寬度、結果兩行截斷與醒目外框契約，以及
  時間線分頁按鈕換行、貼文卡片無固定寬度、留言回覆縮排與內容換行契約，以及
  通話卡片／列無固定寬度、內容換行與操作列換行契約，以及貼圖網格
  自動填充欄位、貼圖包卡片無固定寬度與搜尋列換行契約。
  真實瀏覽器驗證須在 CI 完成，本機無 Chromium。執行：`node tests/responsive-audit.mjs`

`tests/entry-*.ts(x)` 為打包入口，不含測試斷言。
