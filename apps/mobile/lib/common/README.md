# 共用程式碼（common）— Phase 01 佔位說明

狀態：Phase 01 空骨架。本目錄不含任何程式碼。

## 位置

`lib/common/` 為 `SPEC-SOURCE.md` §26 目錄規範所列的共用目錄，與 `lib/core/`、
`lib/features/`、`lib/design_system/` 並列。本階段僅保留目錄位置，不放任何共用程式碼。

## 規則

- 共用程式碼的實際內容與邊界，待後續階段依模組責任劃分後再定，不得在本階段預寫。
- 不得把功能程式碼塞入共用目錄以規避 feature 目錄劃分（`SPEC-SOURCE.md` §27 第 7 條）。
